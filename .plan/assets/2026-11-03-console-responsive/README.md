# 콘솔 반응형 화면 검증

2026-11-03, PR #240. 기존 문서 전체의 가로 overflow 검사만으로는 내부 잘림과 겹침을 발견하지 못했다. 이번에는 실제 렌더링을 캡처하고 화면을 조작하며 확인했다.

## 데이터와 범위

- 로컬 orchestration-server의 프로젝트 10001을 GET/HEAD 전용 proxy로 조회했다. TC·런·QA 이력·빌드·멤버 데이터가 있는 화면과 데이터가 없는 화면을 함께 확인했다. 운영 DB에는 쓰지 않았다.
- `matrix-*.jpg`: 대시보드, TC, 테스트 런, Macro, QA 실행, QA 히스토리, 이슈, 성능, 기획 문서, 게임 빌드, 화면 지도, 지식 그래프, 설치 안내, 사용량, 멤버, 설정. 16개 경로 × 320/768/1440px × light/dark = 96개 화면. `matrix.json`은 문서 가로 overflow와 화면 alert 기록이다. 이 수치와 별도로 캡처를 직접 비교했다.
- `tc-{width}-{theme}.jpg`: 실제 TC 1개를 표시한 320/360/390/480/640/720/721/768/1024/1280/1440px 목록. 모바일에서는 필터와 표를 본문 스크롤로 이동하고, 표 안에서는 가로로 이동한다.
- `sheet-*.jpg`: 실제 TC 편집 창. light 320×640/360×900/390×844/667×375/844×390/1024×768, dark 320×640/667×375/844×390. 짧은 화면에서도 저장·취소 버튼이 보이고 높이가 44px인지 확인했다. 편집 데이터는 저장하지 않았다.
- `import-*.jpg`: 320×640/360×900/667×375/1024×768의 TC 가져오기. 모달 내부의 세로 스크롤과 표 가로 스크롤을 확인했다. `import-selected-360-dark.jpg`는 선택 후 붙이기 버튼 활성화 상태다. 실제 붙이기는 하지 않았다.
- `canvas-chat-360-dark.jpg`: 런 캔버스와 하단 대화 패널. 대화 접기/펴기, 전체 보기, 입력 칸 접근을 확인했다.
- `qa-history-inspector-360-dark.jpg`: 실행 선택 후 하단 상세와 링크의 키보드 접근을 확인했다.
- `fixture-selection-360-dark.jpg`: 별도 API fixture의 TC 18개를 전체 선택한 상태다. 실제 backend 데이터와 구분한다.
- `before-360.jpg`: 수정 전 재현 화면이다.

## 조작 확인

프로젝트 select 이동, 뒤로/앞으로 이동, 시나리오 상세의 테스트 런 선택값, agent 비활성일 때 대화 메뉴 제외, desktop 레일 접힘 설정 보존을 확인했다. TC 표의 오른쪽 끝까지 ArrowRight로 이동했고 390px에서 scrollLeft 819.33/max 819였다. 가져오기 표도 360px에서 scrollLeft 858.67/max 859까지 이동했다.

## 한계

이 기록은 Chromium의 로컬 렌더링 확인이다. 비어 있는 성능·문서·지식 화면의 데이터가 채워진 모든 상태, 운영 환경, Safari/Firefox, 브라우저 200% zoom은 확인하지 않았다. 서버 쓰기·실제 QA 실행·대화 전송은 이번 화면 검증에 포함하지 않았다. 스크린샷은 자동 회귀 테스트를 대신하지 않는다.

## 코드 검증

`npm run build`, `npm test` 164 suites/1,605 tests, 변경 TSX의 ESLint, `git diff --check` 통과. 독립 코드 리뷰에서 발견한 모바일 봇 작업 표시 영역과 긴 작업자명 잘림도 수정하고 PASS를 받았다.

최신 develop의 TC 종류·도착 화면 기능을 병합한 뒤에도 build와 1,605개 테스트가 통과했다. TC 22개 폭·테마 조합과 편집 창 9개 조합을 다시 확인하고 해당 캡처를 교체했다. `tc-widths-after-merge.json`에 목록의 재검증 결과가 있다.
