# 콘솔 모바일 레이아웃 수정

상태: 구현 완료

## 변경 범위

- 모바일 헤더, 프로젝트 메뉴, 페이지 여백과 제목 크기를 조정했다.
- 시나리오 편집 화면과 QA 히스토리를 세로로 배치하고 각 영역의 스크롤을 유지했다.
- QA 실행 선택 창과 두 Picker의 너비를 뷰포트 안으로 제한했다.
- 관리자 화면의 필터 줄바꿈과 표 컨테이너 너비를 조정했다.
- 최신 스크롤 래퍼에 모바일 높이를 전달하고, 숨김 메뉴 그룹 레이블의 위치 기준을 지정했다.

## 검증 결과

- `npm run build`, 변경 TSX 파일 ESLint, `git diff --check` 통과.
- 28개 경로를 320, 390, 768, 1024, 1440px와 light/dark 조합으로 점검했다.
- 최신 기준 브랜치에서 발견한 편집 화면 높이와 숨김 메뉴 레이블의 가로 넘침을 수정하고 편집 경로 2개를 다시 점검했다.
- API mock을 사용한 로컬 production build 검증이다. 실제 인증, 권한, 저장 요청의 연동 증거는 아니다.
- 기존 대형 bundle 경고가 남아 있다.

## 복구 방법

이 변경의 commit을 revert한다. 데이터나 설정 migration은 없다.
