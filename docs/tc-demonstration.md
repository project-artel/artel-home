# TC 검증 시연 사용

Scenario 화면에서 사람이 게임을 조작하고 판정한 기록을 검증 절차로 정리한다. 절차를 승인하면 같은 TC 내용과 게임 build에 대한 이후 QA에서 참고한다.

## 시연과 판정 저장

1. Scenario에 검증할 TC를 추가한 뒤 **TC 검증 시연**을 연다.
2. TC와 연결된 게임 인스턴스를 선택하고 **시연 시작**을 누른다. 지원하는 SDK가 연결된 인스턴스만 시작 목록에 표시된다.
3. 게임 화면을 클릭해 마우스로 조작한다. 화면에 focus가 있으면 키보드 입력도 게임에 전달된다. `Tab`은 화면 탐색에 사용하고 `Escape`는 시연 조작을 중단한다.
4. 판정할 장면에서 **이 화면 판정**을 누른다. 해당 장면을 고정하고 조작을 종료한 뒤 PNG를 저장한다.
5. **통과**, **실패**, **판단 보류** 중 하나를 누르면 판정이 저장된다. 기대 결과는 기존 TC 값을 사용한다. 설명은 필요한 경우에만 덧붙인다.
6. 서버가 남은 게임 적용 결과를 정리하면 Agent가 검증 절차를 자동으로 작성한다. 다른 장면이나 특정 영역을 사용하려면 접힌 **저장된 장면 선택**, **판정 영역**을 연다.

다른 창으로 이동하거나 탭을 숨기거나 연결이 끊기면 입력 제어가 종료된다. 눌린 입력은 해제되며 자동 재연결·재전송하지 않는다. 다시 조작할 때는 새 시연을 시작한다. 게임 화면 밖으로 focus를 옮기면 눌린 키와 버튼을 해제한다. **이 화면 판정**은 입력 제어를 종료하므로 판정 중에는 게임으로 입력을 전달하지 않는다.

연결이 끊겨도 마지막 영상과 이미 저장한 장면을 확인할 수 있다. 이미지 업로드가 실패하면 화면을 유지한 채 다시 시도한다. **저장된 시연**에서 이전 기록을 다시 열 수 있으며, 기능이 꺼져 있어도 저장된 기록은 읽을 수 있다.

## 검증 절차 승인

판정을 저장하면 정리가 끝난 기록에서 검증 절차를 자동으로 작성한다. 자동 추출이 실패하면 **검증 절차 초안 작성**으로 재시도한다. 기본 요약에서 시작 조건, 수행 절차, 완료 조건과 판정 조건을 검토한다. 내용을 바꾸거나 출처를 확인하려면 **절차 수정**을 연다. 관찰한 현상과 판정 근거는 Agent가 원본에서 정리하며, 근거가 부족하면 미해결 질문으로 남긴다.

수정했다면 **초안 저장**을 누른 뒤 **QA 활용 승인**을 누른다. 미해결 질문이 남아 있거나 저장하지 않은 수정이 있으면 승인할 수 없다. 승인된 절차는 **승인 철회**로 이후 QA에서 제외할 수 있다. 이미 시작한 QA에는 실행 당시의 절차가 기록된다.

원본에 장면이나 판정을 추가하면 기존 절차의 승인이 무효화된다. 변경된 기록으로 절차를 다시 만들고 검토한다. 시연에서 실패를 표시해도 TC의 QA 결과 자체를 변경하지 않는다.

## 장면과 입력 기록 범위

- 사람이 저장한 판정 장면은 클릭 당시 video frame을 PNG로 보관한다. 최대 해상도는 1920×1080, 이미지 하나의 최대 크기는 2MiB다.
- 조작 context를 위해 첫 장면, 키·버튼 입력 전, 입력 해제 후 장면도 자동 저장한다. 자동 저장은 최소 250ms 간격, 세션당 60장으로 제한한다. 업로드 중에는 가장 최근 대기 장면 하나만 유지한다. 이 제한은 사람이 직접 저장하는 판정 장면에는 적용하지 않는다.
- 영상과 SDK 상태는 서로 다른 시각에 도착할 수 있다. 자동 장면이 SDK 적용 직전·직후임을 보장하지 않는다. Browser는 SDK 처리 결과가 저장된 뒤 오는 ACK를 기다렸다가 다음 입력을 전송한다. 처리 실패도 ACK를 받을 수 있으므로 성공 여부는 별도의 ACTION_RESULT에서 확인한다. 결과를 알 수 없는 시간 초과는 제어를 종료한다.
- 게임 조작은 데스크톱 마우스와 키보드를 사용한다. 작은 화면에서는 저장된 장면과 검증 절차를 검토할 수 있다.

## 서버 설정

Orchestration의 `artel.demonstration.enabled`로 새 시연 시작을, `artel.demonstration.qa-enabled`로 승인된 절차의 QA 전달을 각각 켠다. 두 값의 기본값은 `false`다. Browser API·SDK·agent-server 배포와 통합 검증을 마친 뒤 활성화한다.

Home에는 별도 기능 flag가 없다. `/api/projects/{projectId}/demonstrations/instances`의 지원 인스턴스 목록으로 시작 가능 여부를 판단한다. 기존 `VITE_ORCHESTRATION_URL`로 orchestration의 public origin을 설정한다.
