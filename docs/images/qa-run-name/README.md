# QA 히스토리 테스트 런 이름 스타일 수정

실행 상세 패널과 판정 검토 화면의 테스트 런 이름에 기본 본문색을 적용했다. 평상시 밑줄을 제거하고 hover 시 밑줄을 표시한다. 기존 링크와 키보드 focus 동작은 유지한다.

build, 변경 TSX ESLint, git diff --check를 통과했다. 실제 로컬 QA6에서 라이트·다크 테마, 좁은 화면, 링크 주소와 키보드 이동을 확인했다. 단순 스타일 수정으로 별도 테스트는 추가하지 않았다.
