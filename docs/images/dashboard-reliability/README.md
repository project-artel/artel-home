# 대시보드 QA 신뢰도 추이 추가

기존 대시보드 KPI 아래에 QA agent 신뢰도를 표시한다. 오탐률·미탐률 추이, 검토 건수 막대, 기간 전체 검토 건수·검토율, 각 비율의 분자·분모를 함께 보여준다. 대시보드의 7일·30일·90일 선택과 연동한다.

## 집계 기준

기존 `/qa-evaluation/reliability` API를 재사용한다. Asia/Seoul 기준 오늘을 포함한 N일이며, 검증 시도 시작 날짜(없으면 판정 기록 날짜)에 현재 최종 사람 평가를 집계한다. 검토 건수는 평가된 검증 시도 수이며 평가 수정 횟수나 평가 작성일별 활동 건수가 아니다. 평가를 수정하면 과거 시도의 집계도 바뀐다.

오탐률은 FP/(FP+TN), 미탐률은 FN/(FN+TP)다. 분모가 없는 날은 `—`이며 그래프 선을 연결하지 않는다. 실제 0%는 점으로 표시한다. 날짜별 누락일의 검토 건수는 0으로 채운다. 판단 불가 평가도 검토 건수에는 포함되므로 두 비율의 분모 합과 검토 건수는 다를 수 있다. 선택 편향 안내를 그래프 아래 유지한다.

## 검증 결과

- 전체 테스트 1,556개 통과. build(typecheck 포함), 변경 파일 ESLint, git diff --check 통과.
- 새 테스트 5개: 서울 날짜 경계 및 7/30/90일, 누락일과 실제 0%, null에서 선 단절, 전체 시도0·검토0, 단일 날짜의 점·막대·상세 표.
- 실제 로컬 프로젝트1: 전체 시도25, 검토4, 검토율16%, 오탐률0%(0/3), 미탐률 미산출(0/0) 확인. 평가는 2026-10-28 하루에만 있어 실제 그래프는 한 점이다. 여러 날짜 추이의 단절은 자동 테스트로 확인했으며 실제 평가 데이터를 추가하지 않았다.
- 7일(10/22~10/28), 30일(9/29~10/28), 90일(7/31~10/28) 전환과 빠른 기간 변경 후 최신 범위 유지 확인.
- 라이트·다크 테마, 키보드 상세 표 펼침, 390px 화면 확인. 페이지 폭390px 유지, 그래프420px·표520px는 폭333px의 내부 영역에서 스크롤된다.
- 독립 pair review PASS, 계획 Fast/Medium/Heavy PASS. React effect 의존성·abort cleanup·접근성·기존 tokens 재사용 확인.
- 로컬 실제 API 화면 검증이다. 배포 환경 E2E 검증은 포함하지 않는다.
